# Моя комуналка — 1.0
Тестовий Android-клієнт Abon.com.ua. Відкриває кабінет у Chrome Custom Tabs або іншому браузері. Авторизація Google здійснюється самим сайтом; браузер може зберігати сесію. Немає власного API, парсингу, передачі cookies у застосунок або нативного відображення балансу. Всі операції з рахунками здійснюються на сайті.

## Збірка через GitHub
1. Створіть репозиторій і завантажте всі файли з архіву у його корінь, включно з прихованою папкою `.github`.
2. Відкрийте Actions → Build Android APK → Run workflow (або зробіть push у main).
3. Після успішної збірки завантажте Artifacts → AbonClient-v1.0, розпакуйте та встановіть app-debug.apk.
4. Перевірте відкриття кабінету, вхід Google та повторний запуск. Для збереження сесії використовуйте той самий браузер.

Збірка debug підписується тимчасовим ключем середовища CI. Для оновлень без видалення старої версії потрібно налаштувати постійний ключ підпису. Код підготовлений для CI, але локальна компіляція не виконувалась.
