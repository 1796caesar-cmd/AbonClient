# 🏠 Моя комуналка — v1.8

Сучасний неофіційний Android-додаток для роботи з особистим кабінетом Abon.com.ua.

## 📥 Завантаження

[**Завантажити останню версію APK**](https://github.com/1796caesar-cmd/AbonClient/releases/latest/download/AbonClient.apk)

## 📱 Основні можливості

- Перегляд особових рахунків.
- Перегляд поточної суми до оплати.
- Подання показників лічильників.
- Автоматичний розрахунок різниці показників.
- Історія показників та платежів.
- Взаєморозрахунки за останні три місяці.
- Автоматичне збереження електронної пошти та пароля.
- Зашифроване збереження пароля.
- Перевірка та завантаження оновлень безпосередньо в додатку.

## 🎨 Персоналізація

Сучасний інтерфейс у стилі Material Design з округлими картками, великими показниками, зручними кнопками та нижньою панеллю навігації.

**Теми оформлення:**

- ☀️ Світла
- 🌙 Темна
- 📱 Як у телефоні

**Кольорові гами:**

- Бірюзова (за замовчуванням)
- Зелена
- Синя
- Блакитна
- Фіолетова
- Помаранчева
- Червона
- Графітова

Вибрані параметри оформлення автоматично зберігаються.
